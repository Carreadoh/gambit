# Gambit

Programa para jugar con mods y trucos con amigos.

**[Descargar Gambit.exe](https://github.com/Carreadoh/gambit/raw/main/Gambit.exe)** (versión 1.0.2)

Novedades de esta versión: Menú F1 nuevo con el estilo de Gambit, avisos arriba a la derecha y marcas VIP nuevas.
