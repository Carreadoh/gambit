# Gambit

Programa para jugar con mods y trucos con amigos.

**[Descargar Gambit.exe](https://github.com/Carreadoh/gambit/raw/main/Gambit.exe)** (versión 1.0.5)

Una vez instalado, Gambit avisa solo cuando hay una versión nueva: aparece el botón **Actualizar** arriba.

Novedades de esta versión: Arreglo: hacer volar el RV ahora anda mientras manejás (W, S, A, D, Espacio y Ctrl). Nuevo: cambiar de marcha con las flechas.
