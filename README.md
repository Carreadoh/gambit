# Gambit

Programa para jugar con mods y trucos con amigos.

**[Descargar Gambit.exe](https://github.com/Carreadoh/gambit/raw/main/Gambit.exe)** (versión 1.0.6)

Una vez instalado, Gambit avisa solo cuando hay una versión nueva: aparece el botón **Actualizar** arriba.

Novedades de esta versión: Arreglo: el RV ahora vuela de verdad y se queda en el aire. W va hacia donde mirás (mirá para arriba para subir), Espacio sube y Ctrl baja.
