# Gambit

Programa para jugar con mods y trucos con amigos.

**[Descargar Gambit.exe](https://github.com/Carreadoh/gambit/raw/main/Gambit.exe)** (versión 1.0.8)

Una vez instalado, Gambit avisa solo cuando hay una versión nueva: aparece el botón **Actualizar** arriba.

Novedades de esta versión: Arreglo: la Lluvia de botín ahora trae los objetos robables de todo el mapa y te caen del cielo alrededor (los VIP primero), sin romperse ni hacer sonar alarmas.
